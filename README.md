# Demo: small custom script (bulk rename + report)

**Nyyo Automation** portfolio sample.

## What it does
One focused job: rename files from a CSV mapping, with a mandatory **dry-run** and a text report.

```bash
python rename_and_report.py --seed          # create demo files
python rename_and_report.py --dry-run       # preview
python rename_and_report.py                # apply + write rename_report.txt
```
